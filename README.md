## Description

This p5.js project demonstrates a simple multi-screen game structure using a state-based approach. The story presents a moral scenario where the player finds a lost phone and must decide what action to take. The player’s choice determines which ending screen is displayed, creating a small branching decision tree focused on ethical decision-making.
